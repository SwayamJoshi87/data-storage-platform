# S3 Drive — File Browser

A personal file browser UI for AWS S3, built on top of the AWS Amplify Storage Browser sample. Lets you upload, browse, preview, and download photos/videos stored in S3. Hosted as a static SPA on Vercel; all media streams directly from S3 to the client (no data proxied through Vercel).

## Stack

- **React 19 + Vite** — SPA, no SSR needed
- **AWS Amplify Gen 2** — Cognito auth + S3 storage backend
- **shadcn/ui + Tailwind CSS v4** — component library and styling
  - Uses `@base-ui/react` under the hood (NOT Radix UI) — see Known Issues
- **TanStack Query** — S3 listing and presigned URL caching
- **Zustand** — UI state (current path, view mode, upload queue)
- **next-themes** — dark/light mode via `localStorage`

## Project structure

```
amplify/              Amplify Gen 2 backend (auth + storage definitions)
src/
  components/
    layout/           AppSidebar, Topbar
    files/            FileCard, FileGrid, FileDetail, UploadZone
    ui/               shadcn auto-generated components
    ThemeToggle.tsx
  hooks/
    useStorage.ts     S3 operations: list, getUrl, uploadData, remove
  store/
    useFileBrowserStore.ts   Zustand store
  lib/
    fileUtils.ts      File type detection, formatting helpers
  pages/
    FileBrowser.tsx   Main page — assembles layout
  App.tsx             Authenticator wrapper + providers
  main.tsx            Entry point — QueryClient, ThemeProvider, Amplify.configure
amplify_outputs.json  Generated by `npx ampx sandbox` — real Cognito + S3 config
```

## Running locally

```bash
npm install
npm run dev        # http://localhost:5173
```

`amplify_outputs.json` must exist with real AWS values. It is generated by:

```bash
npx ampx sandbox   # requires AWS credentials in env or ~/.aws/credentials
```

## S3 bucket paths

The bucket has three access-controlled prefixes:

| Path | Who can access |
|------|---------------|
| `public/*` | All authenticated users (read/write) |
| `admin/*` | `admin` Cognito group only (read/write); others read-only |
| `private/{identityId}/*` | Only the owning user (scoped to Cognito Identity Pool ID) |

## Key design decisions

- **Data flows directly S3 → client** via presigned URLs (`getUrl()` with 1h expiry). Nothing goes through the server.
- **shadcn/ui uses base-ui, not Radix** — `asChild` on `DropdownMenuTrigger` and `TooltipTrigger` does NOT work. Render these as their own button elements; don't nest a `<Button>` inside them.
- **Private path 403 guard** — the sidebar skips listing `private/` until `identityId` is resolved via `fetchAuthSession()`.
- **Theme** defaults to dark, stored in localStorage by next-themes.
